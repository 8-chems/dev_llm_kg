# Neo4j Graph Schema Conventions

## Nodes
All nodes adopt label `:Entity` along with specific domain labels (`:Person`, `:Organization`, `:Location`, `:Concept`, `:Product`).

### Properties
- `id`: `STRING` (stable, unique entity identifier)
- `name`: `STRING` (primary display name)
- `aliases`: `LIST<STRING>` (synonyms, alternate spellings)
- `labels`: `LIST<STRING>` (list of domain labels)
- `summary`: `STRING` (short textual description, max 200 chars)
- `degree`: `INTEGER` (precomputed degree count)
- `embedding`: `LIST<FLOAT>` (1024-dim vector representation)

## Relationships
Relationship types are formatted in `UPPER_SNAKE_CASE` (e.g. `WORKS_FOR`, `LOCATED_IN`, `PRODUCED_BY`, `PART_OF`, `PARTNER_WITH`).

### Properties
- `source_doc`: `STRING` (provenance document reference)
- `confidence`: `FLOAT` (range 0.0 to 1.0)
- `inferred`: `BOOLEAN` (true if generated by LLM extraction/inference)
